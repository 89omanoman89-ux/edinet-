# P3: 限定した財務標準化と原本lineage

P2固定標本と、明示的parentDocIDで結ばれた利用可能な親書類だけを対象にする。
標本を成功した書類へ入れ替えない。市場データ結合、投資・仮説研究、全市場展開は対象外。

## 定義と意味

`registry/financial_definitions_v1.json`はRevenue/Sales、Operating Profit、Net Profit、
Total Assets、Equity/Net Assets、CFO、CFI、Shares、EPS、BPSだけの版付きallowlist。
33ルールのaccepted QNameはnamespaceの版を含む完全一致であり、類似タグ検索によるmappingは行わない。
公式schemaのperiodTypeと数値型を確認した201個のQName、17個のschemaのURL・バイトhashを登録した。
未知の版・企業独自タグ・対象外タグは`unknown_mapping`として候補に残す。
独自タグの標準タグとの関係を検証する実装はないため、自動採用しない。

次の意味は別metricまたは別semantic keyに分離する。

- 売上高とIFRS収益。銀行等の営業収益を一般事業会社の売上へ自動変換しない。
- 利益合計と親会社帰属利益。純資産合計・株主資本・IFRS資本合計・親会社所有者帰属持分。
- duration/instant、annual/cumulative/quarter、連結/単体、JP GAAP/IFRS、dimensions。
- 発行済株式総数と期中平均・自己株控除後株数。今回採用するのは発行済総数だけ。
- 元報告の基本EPS/BPSと自計算値。分割調整はせず`as_reported_not_split_adjusted`を維持。
- CFO+CFIとCFO-CapExはともに未実装で、同じFCFへ統合しない。

IFRSの`EquityToAssetRatioIFRSSummaryOfBusinessResults`は名称による推測を避け、
公式のperShareItemTypeと「1株当たり親会社所有者帰属持分」のラベルを確認してBPSの別定義へ登録した。
US GAAP連結値は未対応。IFRS/US GAAP書類に併載された、明示的な単体contextのJP GAAP要素は区別して保持する。

参照した一次資料：

- [金融庁 2023年版EDINETタクソノミ](https://www.fsa.go.jp/search/20221108.html)と原本のschema import先。
- [報告書インスタンス作成ガイドライン](https://www.fsa.go.jp/search/20221108/2b-1_InstanceGuide.pdf) 5-4（context）、5-6（数値・nil）。
- [XBRL 2.1](https://www.xbrl.org/Specification/XBRL-2.1/REC-2003-12-31/XBRL-2.1-REC-2003-12-31+corrected-errata-2013-02-20.html)のcontext/unit/numeric item。

## 原本への逆引き

`financial_facts.py`は32 MiBのZIP展開制限、重複member拒否、DOCTYPE/ENTITY拒否を維持し、
namespaceのスコープを解決する。文書IDと原本hash/bytesを検証してからXMLを読む。
各候補・canonical factに原本SHA-256、member名/SHA-256、element index、完全QName、
元文字列/属性、contextRef・context XML/hash、unitRef・元unit、期間、dimensions、scope、
会計基準、公開時刻、抽出法、definition version/hash、verificationを保持する。
metadataの証跡は`documents.jsonl`へ結び付ける。

XBRL instanceの値は既に元unitの実数値であり、`decimals=-6`を百万円の倍率とは解釈しない。
JPY、shares、JPY/sharesだけを受け入れ、未知単位や通貨換算を推測しない。Decimalで元精度を保つ。
contextの実日付を保持し、既知のEDINET context命名規則と当期DEI期間を照合する。
明示的NonConsolidatedMemberを単体とし、対象財務contextのdimension省略はDEI=trueと併せて連結と判定する。
その他のdimension、未確認scope・期間・基準は理由付きnull。nilも0へ置き換えない。

全canonical候補をZIPから再抽出し、保存予定の値・context・unit・定義・locatorが完全一致することを検査する。
これは同じ抽出器による決定論的な逆引き検査であり、独立パーサによる会計的正確性の認証ではない。

## PITと訂正

`public_available_at`は提出日時以降。分精度のmetadata時刻はその分の末尾を保守的上限とし、
日付だけなら翌日0時JST。比較年の値を対象年度に遡及して利用可能とは扱わない。
metadataに編集があれば編集時刻も考慮し、不明なら公開時刻不明として止める。
現在の観測時刻・過去取得ログの主張・公開時刻を別フィールドで保持する。

`financial_views.fact_view`は`as_reported`（書類指定）、`as_of`（decision時刻指定）、
`latest_restated`（snapshot内の最新明示的訂正）を区別する。
訂正系列はparentDocIDのみで構成し、提出主体不一致・循環・分岐・親不在は拒否/BLOCKED。
異なる有報の比較値を同じ企業・年度だけで同一訂正系列へまとめない。
最新訂正に値がない、nil、取下げ、抽出不能の場合は旧値へfallbackしない。
各候補を保存し、snapshot cutoffと厳密な`available_at < decision_at`を適用する。
system replayは実際の過去取得時刻も要求し、現在の再構成を過去の取得成功へ昇格させない。

## Reconciliationと派生lineage

同一提出主体・期間・metricの全候補を保持し、exact match / scope difference /
accounting-standard difference / restatement difference / unit difference / conflicting facts /
unresolvedに分類する。平均や任意の優先順位で1つへ統合しない。
同じ意味の競合候補はビューでもBLOCKED。exact duplicateもlocatorを残す。

`derive_quarter`は加算可能flowだけを、同一書類vintage・年度起点・scope・基準・unit・dimensionsの
累計差分から作る保守的な経路。EPS/BPSや株数の差分は拒否する。
欠損・proxy・未検証の入力から値を作らず、syntheticフラグを伝播する。
`validate_lineage`は入力IDの存在、循環、定義版、再計算値、公開時刻を検査する。
実標本は有報中心のため、この派生経路の受入は合成fixtureで行い、実四半期検証済みとは呼ばない。
負債全体のmappingを追加していないため、貸借一致検査は今回NOT RUN。

## 私有実行

```sh
python p3_audit.py --edinet-local-root /absolute/private/edinet --p2-snapshot /absolute/private/p2/frozen-snapshot --private-dir /absolute/private/p3 --snapshot new-unique-snapshot
python -m unittest discover -s tests -v
```

抽出前に固定対象・親書類の閉包（上限50件）・定義・コードhash・P2 fingerprintを保存する。
Git内、入力配下、既存snapshotへの出力は拒否する。元原本とP2成果物はread-only。
主成果物にsnapshot ID、code SHA、definition version、synthetic、export_allowedを付ける。

| 私有成果物 | 内容 |
|---|---|
| audit_plan.json / canonical_fact_definitions.json | 結果を見る前の対象・コード・定義版 |
| documents.jsonl | 元metadata行/locator・訂正関係・公開時刻・原本manifest |
| xbrl_fact_candidates.jsonl / canonical_facts.jsonl | 全数値候補と限定mapping、理由付きnull |
| metric_coverage.jsonl | 書類×対象分野の候補不在/全候補BLOCKED。取れない値はnull |
| reconciliation.jsonl / lineage.jsonl | 候補間差異・原本/定義までの辺 |
| failure_ledger.jsonl / view_audit.json | 書類/候補の失敗理由・最新訂正ビューのBLOCKED |
| coverage_summary.json / preservation_proof.json | 集計・全値逆引き検査・入力不変の証跡 |

公開Gitへ数値個票・実doc_id・原本・metadata行・私有絶対pathを追加しない。
rights reviewはBLOCKED、`export_allowed=false`を維持。全市場代表性はNOT ESTABLISHED。
